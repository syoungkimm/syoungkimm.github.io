2-2. 실행 순서 필수

Oracle은 FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY 순서로 실행한다. SELECT 별칭은 ORDER BY에서만 쓴다.

  • 집계 함수는 WHERE에 쓰지 않는다. 집계 조건은 HAVING에 쓴다.

2-3. T2 GROUP BY 템플릿 필수

SELECT HOST_ID, COUNT(*) AS CNT
FROM PLACES
WHERE 조건
GROUP BY HOST_ID
HAVING COUNT(*) >= 2
ORDER BY CNT DESC, HOST_ID;
입력 예시
PLACES
ID | NAME | HOST_ID
1  | A    | 10
2  | B    | 10
3  | C    | 20
4  | D    | 30
5  | E    | 30
6  | F    | 30
(WHERE 조건 줄은 빼고 실행)
실행 결과
HOST_ID | CNT
30      | 3
10      | 2
-- HOST_ID 20은 1개라 HAVING에서 빠진다
  • GROUP BY에는 SELECT 별칭을 못 쓴다. GROUP BY CNT는 오류다. ORDER BY에서는 별칭을 쓴다.
  • SELECT에 쓴 일반 컬럼은 모두 GROUP BY에 넣는다. 빠지면 ORA-00979가 난다.
  • COUNT(*)는 NULL 행을 센다. COUNT(컬럼)은 NULL 행을 빼고 센다.

2-4. T3 JOIN 템플릿 필수

-- 양쪽 모두 있는 행
SELECT B.BOOK_ID, A.AUTHOR_NAME
FROM BOOK B
JOIN AUTHOR A ON B.AUTHOR_ID = A.AUTHOR_ID;

-- 한쪽에만 있는 행 찾기
SELECT O.ANIMAL_ID, O.NAME
FROM ANIMAL_OUTS O
LEFT JOIN ANIMAL_INS I ON O.ANIMAL_ID = I.ANIMAL_ID
WHERE I.ANIMAL_ID IS NULL
ORDER BY O.ANIMAL_ID;
입력 예시
BOOK               AUTHOR
BOOK_ID | AUTHOR_ID  AUTHOR_ID | AUTHOR_NAME
1       | 1          1         | 김작가
2       | 2          2         | 이작가
3       | 1

ANIMAL_OUTS          ANIMAL_INS
ANIMAL_ID | NAME     ANIMAL_ID
A1        | Lucy     A1
A2        | Max      A3
A3        | Bella
실행 결과
-- 첫 번째 쿼리
BOOK_ID | AUTHOR_NAME
1       | 김작가
2       | 이작가
3       | 김작가

-- 두 번째 쿼리: OUTS에만 있는 동물

A2        | Max

테이블 별칭 앞에 AS를 쓰지 않는다. FROM BOOK AS B는 Oracle에서 오류가 난다.

2-5. T4 상위 N 템플릿 필수

-- 상위 3개 (Oracle 12c 이상)
SELECT NAME, DATETIME
FROM ANIMAL_INS
ORDER BY DATETIME
FETCH FIRST 3 ROWS ONLY;

-- 동점까지 모두 출력
FETCH FIRST 1 ROWS WITH TIES;

-- 구버전 대비: ROWNUM은 정렬한 서브쿼리 밖에서 쓴다
SELECT * FROM (
  SELECT NAME FROM ANIMAL_INS ORDER BY DATETIME
) WHERE ROWNUM <= 3;
입력 예시
ANIMAL_INS
NAME | DATETIME
Jack | 2013-07-10
Ella | 2014-02-20
Max  | 2013-10-02
Lucy | 2014-08-01
Kia  | 2013-07-10
실행 결과
-- FETCH FIRST 3 ROWS ONLY
NAME | DATETIME
Jack | 2013-07-10
Kia  | 2013-07-10
Max  | 2013-10-02
-- Jack과 Kia는 날짜가 같아 둘의 순서는 보장되지 않는다

-- FETCH FIRST 1 ROWS WITH TIES
NAME | DATETIME
Jack | 2013-07-10

3-2. 자주 쓰는 함수 필수

함수 용도 주의
[[0]*m for _ in range(n)] 2차원 배열 [[0]*m]*n은 행 n개가 1개의 리스트를 공유한다
a.index(x) 첫 위치 값이 없으면 ValueError가 난다. 문자열은 find로 -1을 받는다
sorted(a), a.sort() 정렬 sorted는 새 리스트, sort는 원본을 바꾼다
enumerate(a, start=1) 인덱스·값 start로 시작 번호를 바꾼다
any(), all() 조건 검사 any는 1개라도 True, all은 모두 True
ord('a'), chr(97) 문자↔코드 ord('a')는 97이다
s.isdigit(), s.isalpha() 문자 판정 숫자로만 된 문자열이면 True다

4-4. T9·T10·T11 BFS/DFS 필수

최단 거리는 BFS로 푼다. 영역 개수는 BFS와 DFS 둘 다 된다. 3일 동안 BFS 1개를 완벽히 외우는 쪽이 낫다.

# T9: 그래프 BFS (백준 1260)
from collections import deque

graph = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    graph[a].append(b)
    graph[b].append(a)          # 방향 그래프면 이 줄을 지운다
for g in graph:
    g.sort()                    # 1260번: 작은 번호부터 방문한다

def bfs(start):
    visited = [False] * (n + 1)
    visited[start] = True       # 큐에 넣을 때 방문 처리한다
    q = deque([start])
    order = []
    while q:
        v = q.popleft()
        order.append(v)
        for nxt in graph[v]:
            if not visited[nxt]:
                visited[nxt] = True
                q.append(nxt)
    return order

3 4

bfs(1) → [1, 2, 3, 4]

# T10: DFS (재귀)
import sys
sys.setrecursionlimit(10**6)

visited = [False] * (n + 1)
def dfs(v):
    visited[v] = True
    for nxt in graph[v]:
        if not visited[nxt]:
            dfs(nxt)

# 타겟 넘버: 모든 경우 탐색
def solution(numbers, target):
    def go(i, total):
        if i == len(numbers):
            return 1 if total == target else 0
        return go(i + 1, total + numbers[i]) + go(i + 1, total - numbers[i])
    return go(0, 0)

# T11: 격자 BFS 거리 (백준 2178, 게임 맵 최단거리)
from collections import deque

def grid_bfs(grid, sr, sc):
    n, m = len(grid), len(grid[0])
    dist = [[-1] * m for _ in range(n)]   # -1 = 아직 방문 안 함
    dist[sr][sc] = 0
    q = deque([(sr, sc)])
    while q:
        r, c = q.popleft()
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < m and grid[nr][nc] == 1 and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return dist

def solve(r, c, size):
    color = grid[r][c]
    if all(grid[i][j] == color for i in range(r, r + size) for j in range(c, c + size)):
        count[color] += 1
        return
    h = size // 2
    for dr, dc in ((0, 0), (0, h), (h, 0), (h, h)):
        solve(r + dr, c + dc, h)

SELECT COUNT(*) AS USERS
FROM (

    GROUP BY USER_ID

-- ID별 개수와 전체 평균의 차이
SELECT USER_ID, COUNT(*) AS CNT,
       ABS(COUNT(*) - (SELECT AVG(COUNT(*)) FROM ORDERS GROUP BY USER_ID)) AS DIFF
FROM ORDERS
GROUP BY USER_ID;

-- 요일별 합계 (월요일부터 정렬)
SELECT TO_CHAR(PAY_DATE, 'DY', 'NLS_DATE_LANGUAGE=KOREAN') AS DAY_NAME,
       SUM(AMOUNT) AS TOTAL
FROM PAYMENTS
GROUP BY TO_CHAR(PAY_DATE, 'DY', 'NLS_DATE_LANGUAGE=KOREAN'),
         TO_CHAR(PAY_DATE - 1, 'D')
ORDER BY TO_CHAR(PAY_DATE - 1, 'D');
